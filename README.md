# Eventra — Responsive Event Management Website

A responsive event discovery and registration website made with HTML5, CSS3 and vanilla JavaScript.

## Features
- Responsive layout for mobile, tablet and desktop
- Event cards with date, category, venue, price and description
- Search events by title, category or location
- Category filtering
- Event detail popup
- Registration form with JavaScript validation
- Registration data saved in browser Local Storage
- Dark/light mode toggle
- Keyboard support for event cards and Escape to close the popup

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. No build tools or installation are required.

## Project structure
- `index.html` — page structure and content
- `style.css` — responsive styling and layout
- `script.js` — event data, filtering, modal and form validation

## Customization
Edit the `events` array near the top of `script.js` to add or change events. Update the title, category, date, time, venue, city, price, emoji, gradient and description.

## Registration note
This is a front-end academic project. Registration details are stored in the visitor's browser using Local Storage; no real server or email notification is connected.

## Deployment
Upload the three website files (`index.html`, `style.css`, `script.js`) to GitHub Pages, Netlify or Vercel. Keep `README.md` in the GitHub repository.
